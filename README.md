# AceXcell.io Landing Page Prototype

A static, mobile-first landing page prototype for showcasing AceXcell.io's landing-page service to prospective small-business clients.

## Files
- `index.html` — page structure and copy
- `style.css` — responsive navy/gold design
- `script.js` — lightweight placeholder for future interactions
- `render.yaml` — Render Static Site configuration

## Deploy on Render
1. Create a GitHub repository and upload these files.
2. In Render, create a **New → Static Site** from the repository.
3. Build command: leave blank.
4. Publish directory: `.`
5. Deploy.

The site is intentionally dependency-free, so it can also be hosted on other static hosting platforms.
